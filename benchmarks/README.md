# benchmarks/

Benchmark harness for nofluke: it measures whether the noise protocol (D8, D9) picks better true optima than "no re-evaluation, best single observation", and how the strategies (D11) compare with random search at equal budget, on synthetic noisy problems with known optima and on a real scikit-learn problem. It is not part of the installed package; the plan is `docs/plans/benchmarks.md`, and results go to `docs/RESULTS.md` as R entries citing run ids.

## What it runs
- **Problems** (`problems.py`, all maximised): `branin` (negated), `hartmann6` (negated), `mixed_hpo` (synthetic training run with log floats, int, choice, bool and a conditional float; optimum computed numerically), and `sklearn_svm` (SVM on the digits data, real noise from a seed-dependent train/validation split; needs scikit-learn, skipped with a message otherwise).
- **Noise** (synthetic problems): total SD = noise ratio x SD of the noise-free value over 10,000 uniform points. The variance is split 50/50: a seed-level offset shared by every candidate evaluated with the same eval seed (common random numbers, D10) plus an independent per-evaluation term.
- **Arms**: `random`, `lhs` (every new candidate from the Latin-hypercube design, `n_init = budget`), `tpe`, `gp` (continuous problems only), each with the protocol on (defaults) and off (`noise.reeval_share: 0`), e.g. `tpe-on`, `tpe-off`; `tpe-raw` etc. is the protocol on without the D14 seed-effect correction (only when asked for explicitly).
- **Workers**: 4 simulated workers, seeded log-normal durations (sigma 0.5), `ask(1)` whenever one frees, results told in finishing order. A run is a pure function of (problem, noise ratio, arm, seed).
- **Metrics per run**: true value and regret (optimum - true) of nofluke's D9 pick, of the best single observation, and of the best candidate ever evaluated; optimism (reported - true) of both picks; re-evaluations; wall time.

## How to run
Always use the project interpreter (`python` in `AGENTS.local.md`); optional extra: `pip install -e '.[optuna,gp,bench]'`.

```bash
# smoke (2 seeds, budget 32, noise ratio 0.5, every problem and arm; about a minute)
python benchmarks/harness.py --smoke --jobs 4
python benchmarks/summarise.py benchmarks/results/<run_id>

# full sweep (ask the owner first: AGENTS.md compute rule)
python benchmarks/harness.py --problems branin,hartmann6,mixed_hpo,sklearn_svm --noise-ratios 0.25,0.5,1.0 \
    --arms random,lhs,tpe,gp --seeds 0-19 --budget 128 --jobs 4 --out benchmarks/results/<run_id>
```

Options: `--keep` stores each run's study folder under `<out>/studies` (default: a temporary folder deleted after the metrics are extracted). Outputs are `manifest.json` (run id, UTC time, versions, git revision and dirty flag, config and hash, arms, problems, seeds, budget) and `results.jsonl` (one line per run; identical between repeats except `wall_s` and `peak_rss_mb`). `benchmarks/results/` is git-ignored except its README. Tests: `tests/test_benchmark_problems.py`.
