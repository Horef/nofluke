## Enforced import boundaries

- `nofluke` must not import `optuna` at module level (except in `nofluke.strategies.optuna_backend`): the core runs with numpy only; Optuna is an optional backend imported lazily (D3)
- `nofluke` must not import `torch`, `jax`, `tensorflow`, `neuron`, `submitit`, `pandas` at module level: nofluke is a general library: no ML frameworks, simulators or cluster clients (D2)
