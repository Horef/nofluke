# src/nofluke/

The nofluke package: study configuration and search space, the append-only journal and its replayed state, the noise
statistics and planner that decide each ask, the `Study` API, local evaluators and the command line. Layering, bottom
up: `rng`, `space` -> `config` -> `journal`, `state` -> `noise`, `strategies` -> `planner` -> `study` -> `runner`,
`cli` (see `docs/ARCHITECTURE.md`).

Folder rules: the core imports only numpy and the standard library (PyYAML is imported lazily by `config.load_config`);
all randomness comes from `rng.derive`; planning is pure; only `journal.py` touches the study folder's files.
